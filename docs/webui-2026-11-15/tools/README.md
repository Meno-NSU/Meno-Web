# Проверка сайта без прода

- `server.mjs` — мок шлюза на :9906: ответы `/v1/models`, `/v1/knowledge-bases`, `/v1/legal/documents`
  с прода (файлы `*.json`, последняя строка — HTTP-код) + сценарии чата по тексту вопроса:
  «ошибка» — сбой на стадии `prepare`, «долго» — длинный медленный ответ, остальное — обычный ответ
  с таблицей, длинными ссылками и источниками. `LITE_STATE=available` — meno-lite «жива».
  Запись отзывов (👍/👎, текст отзыва, опрос, голос арены) отвечает `{status: ok}`;
  `POST /mock/state {"fail": true, "delayMs": 2500}` прямо на :9906 делает её ошибкой 500 и/или
  медленной, `GET /mock/log` — что пришло (чтобы считать дубли), `DELETE /mock/log` — очистить.
- Сайт: `BACKEND_URL=http://127.0.0.1:9906 npx vite --port 5199` в checkout Meno-Web.
- `cdp.mjs` — драйвер headless Chrome по DevTools Protocol (Node 24, без зависимостей).
- `scenario.mjs <outdir> [mobile|desktop]` — скриншоты и метрики (переполнение, шрифт поля отзыва,
  кнопка копирования во время генерации, положение значков источников); `SITE=` — другой адрес.
- `jitter.mjs <outdir>` — покадровый замер высоты заголовка обработки и положения текста ответа.
- `picker.mjs <outdir>` — меню версий, группа «Менон 1.0».
